{% comment %} Field — renders one Django bound field: label, control, help text, errors. Parameters: field bound field (required), e.g. form.title label optional label override (default: field.label) help optional help text override (default: field.help_text) hide_help truthy -> no help text at all, not even the form's help_text (use it when the help only repeats the label or placeholder) required True / False -> force or drop the "*" marker (default: the form field's own `required`) rows height of a textarea (default: what the form sets) class optional extra classes for the wrapper, e.g. "col-md-6" hide_label truthy -> label is kept for screen readers only Behaviour: - label is linked with for=; required fields get a "*" marker - the control keeps the classes set in the form and gets form-control / form-select / form-check-input when it has none of them - with errors: control gets .is-invalid + aria-invalid, every error is listed, and aria-describedby points at help and error text - single checkboxes render as a check row; radio groups and checkbox lists render inside a
; hidden fields render bare Always pass `only`. Example:
